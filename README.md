# AI-Based Punctuation Restoration System

## Overview

An AI-based application that converts speech into text using Whisper and restores missing punctuation using a deep multilingual model.

## How It Works

Audio Input
↓
Whisper Speech-to-Text
↓
Text Preprocessing
↓
Punctuation Restoration
↓
Final Readable Text

## Technologies Used

- Python
- Whisper
- Deep Multilingual Model
- Flask
- HTML
- CSS
- JavaScript

## Features

- Speech-to-text conversion
- Automatic punctuation restoration
- Text preprocessing
- Output validation
- Simple web interface

## Purpose

The project was built to make raw speech transcripts easier to read and understand by automatically adding appropriate punctuation.
